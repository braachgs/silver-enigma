Installing on Android

  1. If this page is open inside another app, open it in Chrome first (⋮ → Open in Chrome).
  2. Tap Download. If Chrome warns about the file type, tap Download anyway.
  3. Open it from the notification or from Files → Downloads, then tap Install. The first time, Android asks you to allow installs from Chrome.

Day Board installs over the existing Day Board app and keeps its settings. Match Board is a separate app.
